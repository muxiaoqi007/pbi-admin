# 嵌入式报表功能实施计划

## 功能范围
1. **报表内嵌预览** — 在工具内直接预览 Power BI 报表（不跳转 Power BI 服务）
2. **嵌入配置** — 获取 embed URL + embed token，方便嵌入到其他应用

## 新建分支
`feature/embedded-reports`

## 实施步骤

### 1. 后端：Embed Token 生成（lib/pbi.ts）

```
generateReportEmbedToken(workspaceId, reportId):
  POST /groups/{wid}/reports/{rid}/GenerateToken
  body: { accessLevel: 'View' }
  返回: { token, tokenId, expiration }

getReportEmbedUrl(workspaceId, reportId):
  GET /groups/{wid}/reports/{rid}/embedUrl
  返回: { embedUrl }
```

### 2. API 路由（app/api/reports/embed/route.ts）

GET ?wid=&rid= → 返回 `{ embedUrl, embedToken, expiration }`

一次调用同时获取 embedUrl 和 token，减少前端复杂度。

### 3. 前端：安装 powerbi-client

```bash
npm install powerbi-client
```

React 19 直接用原生 SDK（不用 React wrapper），动态 import 避免 SSR 问题。

### 4. 新组件：EmbedReportModal（components/EmbedReportModal.tsx）

大型 Modal（90vw × 85vh），内含两个 Tab：
- **报表预览**：用 powerbi-client 的 `embed()` 渲染报表，支持筛选、翻页等交互
- **嵌入配置**：显示 embedUrl、embedToken（带复制按钮）、过期时间，以及 JSON 配置片段

### 5. 报表页操作列（app/reports/page.tsx）

操作列加「预览」按钮 → 打开 EmbedReportModal

### 6. 权限说明

- 服务主体需在报表所在工作区有 Viewer+ 角色
- 世纪互联和国际版由 CLOUD_PRESETS 自动适配（embedUrl 域名不同但逻辑一致）
- 401/403 时显示中文引导文案

## 验证方式
- 构建 + 在真实租户上验证报表预览
- 确认 embed token 生成、复制功能正常
